
# ROS2 Development

This directory contains the ROS 2 software developed for the robot, including packages, nodes, launch files, configuration files, and robot descriptions.

The ROS 2 workspace uses **Colcon** as its build system.

## 1. Prerequisites

Before building the workspace, ensure that you have:

- ROS 2 Jazzy installed.
- Colcon installed.
- Required ROS 2 dependencies installed.

Source your ROS 2 environment before working:

```bash
source /opt/ros/jazzy/setup.bash
```

## 2. Workspace Structure

```text
ROS2/
│
├── src/
│   ├── package_1/
│   ├── package_2/
│   └── ...
│
├── launch/
├── config/
└── README.md
```

All ROS 2 packages should be placed inside the `src/` directory.

## 3. Building the Workspace

Navigate to the ROS2 directory:

```bash
cd ROS2
```

Source the ROS 2 environment:

```bash
source /opt/ros/jazzy/setup.bash
```

Build the workspace:

```bash
colcon build
```

After a successful build, source the workspace:

```bash
source install/setup.bash
```

You can now execute your ROS 2 packages and nodes.

## 4. Running ROS 2 Packages

To execute a node:

```bash
ros2 run <package_name> <executable_name>
```

To launch a system:

```bash
ros2 launch <package_name> <launch_file>
```

Replace the placeholders with the appropriate package, executable, and launch file names.

## 5. Rebuilding After Changes

Whenever you modify the source code, rebuild the workspace:

```bash
colcon build
source install/setup.bash
```

To build only a specific package:

```bash
colcon build --packages-select <package_name>
```

## 6. Important Git Guidelines

The following directories are generated during the build process and **must not be committed to Git**:

- `build/`
- `install/`
- `log/`

These directories are automatically generated by Colcon and should remain local to each developer's machine.

Only commit source code, package configuration files, launch files, and other necessary project resources.

**Note:** Each ROS 2 package should include its own `package.xml` and the appropriate build configuration (`CMakeLists.txt` or `setup.py`).
